# Материалы бренда «Паллетика»

Источник: архив заказчика `02-11-2026_17-31-27.zip`, 3 ноября 2026.

- `original-logo.svg` и `original-logo.png` — исходные материалы без изменений.
- `symbol-transparent.svg` — веб-версия исходного модульного знака: чистые SVG-контуры без встроенной фотографии, белого фона и пустых полей. Геометрия восстановлена по знаку из исходника, цвета — серый и мятный. Используется в шапке, подвале, favicon и концепции кабинета.
- Название рядом со знаком — живой текст Manrope 650, цвет `#2a2c2b`. Горизонтальная компоновка подготовлена 5 ноября 2026 по запросу заказчика: удалить белый фон, сделать название читаемым и уменьшить навигацию.
- `logo.svg` — предыдущая версия с исходным изображением и более плотным окном просмотра; больше не подключается к странице. Сохранены знак, надпись, цвета и пропорции. Изменён только viewBox, удалена внешняя декларация DTD. Встроенное растровое изображение осталось исходным, поэтому файл не зависит от сторонних серверов.
- `symbol.svg` — окно просмотра того же файла вокруг исходного знака; используется в favicon и иллюстрациях кабинета и партнёрской сети.

Полный архив и брендбук сохранены локально в `materials/palletika-2026-11-02`; файлы печати и брендбук не публикуются. SVG из вложенного набора содержит ссылку на внешнее изображение; применён самодостаточный SVG из корня архива. Некоторые иконки вложенного набора экспортированы с пустым белым квадратом, поэтому не используются.

Оранжевые акценты интерфейса сохранены по последнему указанию заказчика. Знак сохраняет серо-мятную палитру и отображается на прозрачном фоне; название выполнено контрастным тёмным текстом. Файл шрифта GetVoIP Grotesque в архиве отсутствует; сохранён локальный Manrope. Показатели и география остаются демонстрационными: подтверждающих материалов в архиве нет.

Цветовой вариант `symbol-orange.svg` подготовлен по запросу заказчика: мятный центральный модуль заменён на оранжевый `#ef532b`. Используется только на отдельной странице `rocket-orange.html`. Геометрия и прозрачный фон совпадают с `symbol-transparent.svg`.
